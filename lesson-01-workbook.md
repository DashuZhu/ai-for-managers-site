# Мои задачи для первой пробы с ИИ

Имя или учебный псевдоним: __________. Отдел / функция: __________. Дата: __________.

Пишите без персональных данных клиентов и закрытых условий компании. Если данных нет, используйте учебный пример и отметьте это.

Примеры для размышления: свести статусы проектов; подготовить черновик письма; сравнить предложения поставщиков; найти повторяющиеся обращения; собрать памятку по утверждённому регламенту; выделить вопросы из записи встречи; подготовить комментарий к проверенной таблице.

## 2. Проверка пригодности

Для каждой задачи ответьте: разрешено ли использовать входные данные? Понятно ли, как проверить результат? Можно ли начать с маленького примера? Есть ли человек, который отвечает за итог? Ошибку можно обнаружить и исправить до внешнего действия?

Если хотя бы один ответ «нет», сначала устраните ограничение. Не компенсируйте риск большим обещанием экономии времени.

## 4. Запрос

«Помоги [кому] выполнить [операцию]. Используй [источник]. Подготовь [результат] в формате [формат]. Сохрани [важные факты]. Если данных не хватает, укажи пробел. Проверь [критерии]. Не выполняй [запрещённые действия]».

Сохраните точный запрос и ответ, чтобы коллега смог повторить попытку.

Если обычное время не измерено, напишите «оценка» или «не измерено». Пример расчёта, не результат внедрения: обычно 30 минут, с ИИ 5 минут подготовки + 4 выполнения + 12 проверки = 21 минута. Разница 9 минут на сопоставимую задачу. Затраты на настройку и подписку учитываются отдельно.

Допустимо не использовать ИИ, если нет разрешённых данных, проверка слишком дорога или задача требует непосредственного человеческого участия. Не вводите рабочие сведения в инструмент интерактивного разбора: там достаточно выбрать общие условия.
