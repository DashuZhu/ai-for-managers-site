# ИИ для менеджеров — открытый сайт

Статические страницы и учебные материалы курса Дарьи Жуйковой. Вход не нужен, формы приёма работ и серверная база отсутствуют.

Публикация: GitHub Pages из ветки main, папка / (root). Основной адрес после настройки DNS: https://aiformanagers.ru/ .

Главная: index.html; третье занятие: lesson-03.html; учебный маскировщик: masking.html. Пути относительные, сайт работает и по адресу проекта GitHub Pages.

Здесь размещены только файлы открытого сайта. Приватные архивы курса, исходники корпоративных презентаций, ключи и данные участников не включены. Учебные файлы третьего занятия вымышлены.
