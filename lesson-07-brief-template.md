# Занятие 7. Шаблон задания на ИИ-решение

## Задание на одну страницу

| Поле | Что заполнить |
| --- | --- |
| Пользователь и процесс | Кто выполняет операцию, как часто и как справляется сейчас |
| Результат | Что получает пользователь и какое решение принимает после этого |
| Входные данные | Форматы, объём, разрешённые источники и правила доступа |
| Первая версия | Какие шаги входят в пробу и какие остаются за её пределами |
| Проверка | Кто принимает результат, где нужна ссылка на исходник и когда система останавливается |
| Экономика | Как сравните время, качество и затраты с текущим способом |
| После запуска | Кто обновляет правила и тесты, разбирает ошибки и отвечает за поддержку |

## Приёмка

Подготовьте минимум пять разрешённых или обезличенных примеров. Для каждого сохраните исходник, ожидаемый результат и способ проверки.

| Пример | Ожидаемый результат | Условие приёмки |
| --- | --- | --- |
| Обычный вход | Таблица требований со ссылками на строки заявки | Все обязательные поля совпадают с источником |
| Вход без срока | Срок отмечен как неизвестный | В таблице нет придуманной даты |
| Два источника расходятся | Обе версии видны, вопрос передан проверяющему | Расхождение не исчезло из черновика |
| Файл нельзя прочитать | Пользователь видит сообщение об ошибке и что делать дальше | Система не заполняет поля по догадке |
| Недопустимое действие | Письмо остаётся черновиком | Отправка без подтверждения невозможна |

Используйте таблицу как пример. Для своей задачи сформулируйте минимум пять критериев, включая качество, обработку ошибки и ограничения действий. Укажите, при какой ошибке вы остановите приёмку.
