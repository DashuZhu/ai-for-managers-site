# ИИ для менеджеров

Открытый сайт курса Дарьи Жуйковой. На главной — оглавление занятий 1–7. У каждого занятия своя страница с материалами и практикой. Для третьего занятия доступны подробный практикум и учебный маскировщик.

- [Открыть сайт курса](https://aiformanagers.ru/)
- [Занятие 7. Как объяснить разработчикам, что вам нужно](lesson-07.html)

GitHub Pages публикует ветку `main` из корня репозитория. Для локального просмотра запустите `python3 -m http.server` из этой папки и откройте http://localhost:8000/.

На сайте размещены учебные материалы. Используйте в упражнениях вымышленные или разрешённые данные.
